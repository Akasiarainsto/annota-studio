# Annota 多模态标注工作台 · 面试演示版

版本 `3.0.0-demo.1`，基于已验收的 `3.0.0-local.3` 工作台。保留音频、视频、图片的完整作业界面与业务规则，使用 GitHub Pages 展示全链路。

在线入口：https://akasiarainsto.github.io/annota-studio/

## 这个版本如何使用

演示角色为 `annotator`、`reviewer_a`、`reviewer_b`、`manager`，演示密码均为 `demo1234`。从标注员开始，在右上角退出后切换角色，依次走完标注、提交、双人复核、分歧仲裁、退回修订与再次验收。角色选择用于流程演练，不是真实账号认证，也不是服务端权限隔离。

任务、复核意见、评测、抽检和导入媒体保存在当前浏览器的 IndexedDB。同一浏览器的不同标签页共享这些数据，各标签页可选择不同角色；不同浏览器、设备和访问者相互独立，不跨设备同步。刷新会保留已保存记录，但撤销栈仅当前编辑会话有效。清除站点数据会删除浏览器中的记录，请事先导出 JSON 和原媒体。

登录页提供“重置演示数据”，清空当前浏览器的演示记录和导入媒体，从四条初始教学任务重新开始。此操作不影响本地服务版和其他访问者。

## 可演示的流程

- 音频：真实波形、人工句段对齐、拖边界、分割合并、撤销重做、属性与正文、WAV 导出。
- 视频：真实原片、镜头 Caption 与七维、撤销重做、临时选区、新建或调整范围、真实 WebM 导出。
- 图片：实拍图、Caption 与标签、矩形区域、移动与缩放、遮挡标注、原像素坐标。
- 自动校验：分模态 JSON / JSONL、九种错例、字段和媒体约束、行列定位、提交拦截及报告导出；不判断语义事实或美学质量。
- 质检：同版冻结、角色分别提交且意见封存、双通过验收、双失败退回、分歧仲裁、复核撤回与更正、重提保留历史。这里的“独立”指流程与意见展示规则，演示使用者仍可切换所有角色。
- 评测与管理：真实模型 A/B 同步播放、评分与证据、原始 ASR CER、分层抽检、Kappa、进度与返工率。指标只来自当前浏览器中的演练操作，不冒充真实业绩。计时使用本机时间，不是受信工时。

完整讲解路线见 [面试演示操作指南](docs/PAGES_DEMO.md)。素材来源见 [SOURCES](docs/SOURCES.md)，组件许可见 [THIRD_PARTY](docs/THIRD_PARTY.md)。公开素材用于工作方法模拟，不代表个人实际参与了这些数据或模型项目。

## 架构与后续部署

`public/src/core` 提供纯校验与片段规则，`public/src/domain` 提供共享任务、计时和统计逻辑；浏览器存储由 `services/demo-*` 适配。IndexedDB 写事务在同一浏览器的标签页间串行处理修订，拒绝旧版本覆盖。导入媒体以 Blob 保存，`media-worker.js` 提供可刷新、可 Range 读取的站点内地址。

Node.js + SQLite 本地服务入口仍在 `server`，通过 runtime-config 将前端切换回本地服务；它复用相同 domain 逻辑。当前演示不会连接你的本机数据库或上传其中的作业。已验收本地工程与数据库另行保留，后续真正部署服务端时再接云端运行与持久化。

## 构建与验证

无前端构建依赖，Node.js 24+：

```sh
node scripts/build-pages.mjs
node --test tests/*.test.js
node tests/pages-workflows.mjs
```

构建生成 `dist`；只把这个静态目录发布到 `gh-pages` 分支，源码保存在 `main`。GitHub Pages 从 `gh-pages` 根目录发布。原静态站点提交保留，可通过 Git 历史回退。`tests/pages-workflows.mjs` 在 `/annota-studio/` 子路径运行三模态完整流程，可用 `ANNOTA_BASE_URL` 指向线上地址；测试使用干净浏览器上下文，不影响访问者数据。浏览器验证需开发机已有 Playwright 与 Edge；不是用户运行依赖。

本地服务版的启动与数据备份说明见 [LOCAL_SERVER](docs/LOCAL_SERVER.md)。它与在线演示使用不同存储，不会自动迁移数据。
