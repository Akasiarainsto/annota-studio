## 本次发现并从源头修复的问题

1. 视频源元素静音导致 MediaElementSource 捕获无声：仅将音频路由至录制流，不静音源元素；重新解码确认音轨 RMS 有效。
2. 新建片段及导入素材后，导出/快捷时长仍停在初始化状态：将按钮与选项状态统一随片段选择和媒体 metadata 刷新，不重建播放器。
3. 突然断网留下活动计时：独立计时服务按账号串行处理，回收无心跳会话，限制单间隔最多 60 秒。
4. 损坏的嵌套 task 造成 500：在 API 数据边界验证对象契约，返回明确 400，业务字段仍由模态规则负责。
5. 表单重复提交、轮询覆盖尚未填写完的意见：提交期间禁用表单，填写中的表单不被后台轮询替换。

## 明确边界

此版以真实协作试用发布，未配置自有 SMTP、邮箱归属验证或找回密码界面。正式业务接入前需补齐邮件体系。当前不含自动语义检查、ASR/OCR 或模型强制对齐，音文对齐是人工时间与转写对应；JSON 通过不代表内容质量通过。

音频导出 PCM WAV；视频在前台按实际播放速度重编码 WebM，有编码开销，不保证帧级精确。突然断电的计时可能多计最多 60 秒。单素材最大 100 MB；当前列表/抽样候选有数量限制，详见使用说明。

开发验收账号/项目与线上环境隔离；线上验收仅用临时测试账号和模拟素材。用户自己的项目需要使用自己的账号创建。本地旧草稿与媒体没有自动上传。
