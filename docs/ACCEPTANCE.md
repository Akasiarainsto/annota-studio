# 本地验收清单

本清单把可操作功能与材料判断分开。测试勾选确认仅验证工作流能执行，不冒充对素材的人工内容验收。

## 音频

- 真实 WAV 播放，真实波形非占位；游标随播放移动，暂停停止。
- 点击片段编号选择；播放图标定位；当前段属性、正文与轨道一致。
- 两侧边界能拖动；共享边界的左右手柄分别占上下区域，避免互相挡住。
- 时间输入改变后原人工确认失效；非法时间明确报错并阻止提交。
- 可分割合并；分割不复制整句到两段，尾段空白需人分配；不同说话人不直接合并。
- 撤销恢复时间、正文和属性；输入框内打空格不触发全局播放。
- 循环播放当前句段，倍速可改；新建说话人可选。
- 快捷 3–10 秒真实 clip 导出；音频文件时长和采样率可核对；JSON 记录 clip 范围。

## 视频与图片

- 视频的媒体节点在编辑正文时不重建；时间轴定位、拖边界、分割合并及确认可用。
- 视频七维与音频字段不同，存疑/不适用有依据。
- WebM 导出真实可解码并含音轨，不以改扩展名冒充片段。
- 图片矩形创建、选择、移动、四角缩放、类别、遮挡和删除可用。
- 缩放和平移不改变原图像素坐标；刷新后媒体和标注仍在。
- 三种模态都能经提交和两人独立通过进入已验收。

## JSON 与错误

- 各模态分别载入合格样例与至少三类错例，检查代码和路径不同。
- 支持 JSON 数组、JSONL、重复键、有限数字、重复任务 ID；错误有行列和定位。
- 修改后重新校验，以实际内容得出结果；导出报告与界面一致。
- 同任务 JSON 可应用到草稿，媒体引用不能替换；重新确认内容后才可提交。
- 内容同音字错误即使格式通过，也不能声称已自动判断正确。

## 独立复核与持久化

- 原标注员不能复核自己；同一复核账号不能重复占两个席位。
- 第一份意见提交后任务仍待复核，对方结论在本轮齐备前不可见。
- 双合格验收，双不合格自动退回，分歧进入独立仲裁。
- 仲裁者不得参与原标注或独立复核；仲裁必须有依据。
- 退回后改新修订，重新提交生成新轮；旧结果、意见和时间可追溯。
- 旧版本保存请求收到冲突，不覆盖服务端新稿；本机草稿可导出、比较恢复。
- 关浏览器或重新启动服务后，本机数据仍保留。

## 评测、管理与布局

- A/B 同步启动、暂停、跳转、倍速；较短片结尾双方同时停；各自全片能看较长尾部。
- 只监听一侧，支持 A/B/静音；低分要理由，未检查允许空分。
- CER 使用原始模型稿，参考正文独立，不因人工修订变成虚假的 0。
- 计时显式开始/暂停；切后台暂停；工时来自服务器，跨任务不串计。
- 管理统计追溯任务，模态分别显示人效；Kappa 有真实配对矩阵和不可计算说明。
- 抽检总体、层、种子与冻结版本可导出。旧轮次抽检样本不静默替换为新轮次。
- 1440×1000、1366×768、暗色及窄屏检查，不出现整页横向溢出；保存、提交及计时有可见入口。

## 复核意见更正（local.2）

- 第二份意见提交前，复核员只能撤回自己的意见，原因必填；原结论保留且不计入当前票数。
- 撤回后能重新填写，另一位复核员看不到本轮被封存的撤回原因与结论。
- 双人结果形成后禁止直接撤回覆盖，通过申请更正进入待处理状态。
- 未参与标注或复核的负责人可重新发起或驳回申请，处理依据必填。
- 重新发起沿用同一冻结标注；旧轮次、原结论与更正记录保留，新轮次重新收集两份意见。
- 更正待处理、已撤回及被替代的配对不混入当前有效 Kappa。

## JSON 与时间轴交互回归（local.3）

- 音频、视频、图片各三种错例，仅改变下拉框就实际载入并检出不同代码；无需额外点击载入。
- 同一错例仍被选中时，修复当前 JSON 后能通过；结果依据实际内容，不根据下拉框伪造。
- 手动输入后旧通过状态立即失效；导出报告与当前文本计算结果一致。
- 视频连续合并后，可用可见的撤销/重做恢复各片段的时间、Caption、属性及说明；无历史时按钮禁用。
- 拖选覆盖已有片段时先显示临时选区，不自动修改文档或直接报重叠。
- 调整当前片段忽略它自身的旧范围，但不能覆盖别的片段；应用后人工确认失效，撤销可恢复。
- 空白处新建成功；重叠新建提示冲突编号且保留原标注；取消不修改标注。
- 选区导出真实媒体而不改变标注；1366×768 下撤销及选区操作入口可见。
- 撤销历史仅当前编辑会话有效；不承诺刷新后恢复先前操作历史。

对应测试：`tests/interaction-regressions.test.js`、`tests/json-video-interactions-browser.mjs`；隔离数据库，结果见 `evidence/json_video_interactions_report.json`。

## 面试演示版（demo.1）

- 全流程复用 domain 规则，以 IndexedDB 替代本机 HTTP 存储；角色为模拟，不声称真实认证。
- `/annota-studio/` 子路径下页面切换、素材、导入文件地址和 Service Worker 均可使用。
- 浏览器间隔离，同一浏览器标签页共享并检查旧修订；导入真实三模态媒体刷新后可读。
- 登录页重置需要确认，恢复四条初始任务，不影响其他浏览器和本地服务版。
- 静态浏览器结果：`pages_browser_report.json` 11 组、`pages_interactions_report.json` 4 组、`pages_corrections_report.json` 2 组、`pages_storage_report.json` 2 组。
