# 面试演示操作指南

## 展示前

推荐 Edge / Chrome，屏幕至少 1366×768。打开在线链接，在登录页点“重置演示数据”开始干净的一轮。明确说明：这是浏览器独立演示，角色是流程模拟，素材与模型输出有公开来源。不要把页面展示的练习统计解释为个人历史业绩。

## 一条可连续讲解的音频流程

1. 选择 annotator（标注员），密码 demo1234，打开“宁夏畜牧业”。播放并查看真实波形，说明以人工句段对齐为首版范围。
2. 修改 S02 的“胎羊皮”为“滩羊皮”，S03 的“皮章”为“皮张”；原始机器稿仍保留，CER 仍对原稿计算。
3. 演示拖边界、输入时间、分割合并与撤销。临时将 S03 结束设为 13.5 秒，展示越界提示和提交阻止，再改回 12.9 秒。逐段核对并勾选边界确认。
4. 保存并提交质检，显示待双人复核和只读冻结版本。
5. 右上角退出，用 reviewer_a 登录；进入质检、打开任务、完成四项检查，选择不合格，填写 S02 术语证据需复查等明确理由。
6. 退出，用 reviewer_b 登录，确认尚看不到甲的封存意见，完成检查并提交合格。形成分歧后，用 manager 处理仲裁，填依据并选择退回。
7. 用 annotator 查看修改与复核记录、补充依据并重新提交，第二轮用甲、乙各自通过，显示验收和两轮历史。
8. 另开 manager 的管理页，查看来源于本轮演练的进度、返工、Kappa 和分层抽检。没有足够配对或 Pe=1 时，Kappa 明确不可计算，不造数字。

## 两个短补充

视频：打开“行动预告”，合并后点击“撤销”恢复。点击“拖选范围”并拖 1–3 秒，先显示临时选区；新建只用于空白处，调整不能覆盖其他片段，导出选区可跨已有标注。新建或修改后须人工确认。到评测页展示左右同步播放、跳转、倍速、共同 8 秒停止和较长候选尾部检查，低分有依据。

图片：查看街边市集实拍来源，框出可见人物区域，移动/缩放并标明遮挡；坐标使用原图像素。Caption 不推断人物身份或关系。图片同样能提交双人复核。

JSON：选择各模态错例，观察实际 JSON 替换及不同错误代码；修改正文后旧结果失效，修正后重跑可通过。强调结构通过不等于内容正确。

## 复核误判

甲提交后、乙提交前：甲可“撤回复核并修改”，原因必填，原记录保留。

双人结果已形成：申请更正复核结论，由 manager 处理，重新发起或驳回；旧意见留存，新轮重新收集意见。

## 数据边界

切角色时使用同一浏览器，或同一浏览器不同标签页；隐私窗口、其他浏览器和其他设备有独立数据。每次保存成功后刷新能恢复任务与导入素材。清除站点数据、登录页重置会删除本浏览器演示记录；任务 JSON 和真实片段可提前导出。导出的 JSON 不含原媒体二进制，也不能自动迁移复核数据库。

公开页面上的角色口令可被所有人看到，因此不能用作真实账号安全或多人生产系统的证明。没有购买服务器或付费托管。

首次载入完成前，工作区暂不接受点击；初始任务只在本浏览器首次建立时下载，后续保存与查询直接使用浏览器数据库。
