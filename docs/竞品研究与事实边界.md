## 二、官方文档说明：从各平台学到什么

### Labelbox

[视频编辑器](https://docs.labelbox.com/horizon/guides/video-editor)描述工具栏、对象列表、播放进度和时间轴；视频目标框的创建或修改会产生关键帧，中间帧插值。整段分类和逐帧分类的作用范围不同。

[音频编辑器](https://docs.labelbox.com/horizon/guides/audio-editor)描述波形、频谱、倍速、时间定位及整条/时域分类。其自动转写属于实际模型服务能力，本地演示不冒充提供该服务。

设计借鉴：媒体与标注对象联动；时间范围清楚；整条标签与片段属性分开。

### SuperAnnotate

[视频编辑器](https://doc.superannotate.com/docs/video-editor)描述左侧目标框/事件等工具、右侧实例列表、底部播放和时间轴，以及批准与驳回操作。

[快捷键文档](https://doc.superannotate.com/docs/multimodal-shortcuts)将 Save、Complete、Quality check、Approve 和 Disapprove 作为不同操作。这些公开页面包含较早更新内容，不代表当前私有工作台的全部行为均被验证。

设计借鉴：保存草稿、提交质检和验收是不同状态；意见要对应当前任务及标注修订。

### CVAT

[编辑器文档](https://docs.cvat.ai/docs/annotation/annotation-editor/)将工作区、工具侧栏和对象侧栏分开。[Track mode 文档](https://docs.cvat.ai/docs/annotation/tools/track-mode-advanced/)说明关键帧、插值和对象离开画面的处理；地址可能重定向到新版文档。

[人工质检文档](https://docs.cvat.ai/docs/qa-analytics/manual-qa/)提供独立 Review 模式、问题定位、评论、解决和重新打开问题的流程。

设计借鉴：视频事件片段和对象轨迹分开；审核默认审阅已有标注；“画框”不能直接称为“模型自动跟踪”。

### Label Studio

[音频分段转写模板](https://labelstud.io/templates/automatic_speech_recognition_segments)先划定音频区间，再为每个区间填写转写，支持 Speech/Noise 标签；片段缺少必填转写时不能提交。

[Audio 标签文档](https://labelstud.io/tags/audio)和[官方音频操作教程](https://labelstud.io/videos/labeling-audio-data-with-label-studio/)说明波形、片段、缩放、倍速和循环试听。新的多声道 React 转写模板具有企业版限制，不能混称为开源基础能力。

设计借鉴：波形拖选、片段列表、右侧只编辑当前片段；让转写作业围绕一次试听展开。

### Scale

[官方概览](https://scale.com/docs/overview)区分标注产品、数据管理与模型分析。[Nucleus 送标注文档](https://nucleus.scale.com/docs/send-to-labeling)说明先配置项目要求，再将数据送入已有标注项目，完成后接回标注结果，新项目可先校准。

公开 SDK 与部分 REST 文档对可支持类型的描述不同；本轮不承诺其全模态 API 行为，也没有验证后台派单或供应商交付。

设计借鉴：先明确标注规范，再作业，再审核交付；无需把账号、计费、云派单搬进面试演示。

### 百度 EasyData

[在线标注文档](https://ai.baidu.com/ai-doc/EasyData/6k9jouf9h)更新时间为 2022-03-11，说明选择数据集版本后进入相应模板，并提供未标/已标、画布、左侧工具与右侧标签栏。该页对音频和视频举的是短素材分类，不足以证明精细听写或视频对象跟踪能力。

[BML 物体检测说明](https://ai.baidu.com/ai-doc/BML/ukhx6dh8i)更新于 2020-11-26，强调添加标签、画框、框紧目标和避免漏标。两份都是历史公开资料，不将其年代隐藏。

设计借鉴：中文操作用语直接，队列状态清楚，标签和当前作业对象有固定位置。

## 三、本地设计选择：哪些是这次独立实现的

- 统一“任务 → 片段/区域/轨迹 → 属性”的数据对象；媒体工具随音频、视频、图片切换。
- 数据标注制作人工记录；数据质检检查人工记录；模型评测检查模型原始输出，三个入口分别呈现。
- 音频使用采样数据绘制波形，支持片段试听和转写；不接真实 ASR。
- 视频同时提供时间片段、七项 Dense Caption、目标框关键帧与线性插值。1/30 秒按钮是演示步进，不声称精确读取了源视频帧率；轨迹仅在首末关键帧内显示，不冒充 AI 跟踪。
- 图片提供 Caption、内容标签、矩形区域及归一化坐标编辑；没有自动 OCR、对象计数或分割推理。
- 草稿允许未完成；提交前检查结构、时间和坐标；审核只能通过或带原因退回；修改会使此前审核失效。
- 纯本地 HTML/CSS/JS；结构化数据保存在 localStorage，导入媒体保存在 IndexedDB。操作由同一浏览器使用者模拟，不是多人权限隔离系统。
- 当前标注 JSON 不含模型评测记录；完整备份用于恢复演示状态，JSON 备份不包含媒体文件本体。
- GitHub 发布属于后续阶段，待用户验收后再部署。

这些选择用于本次面试场景，不是竞品内部代码的复制，也不是对竞品全部功能的等价实现。

## 四、素材与简历事实边界

- Dolphin 预置会议通知、出行提醒是本机合成普通话，噪声样例为程序生成。它们用于练习时间对齐、转写和属性，不是实际方言、维吾尔语或客户录音。
- Seedance 小球视频为程序动画，异常版本为人为构造错例，不是 Seedance 模型真实生成结果。七项描述对应主体、动作时序、运镜、光影、物理动态、材质、交互。
- Seedream 果铺图为程序绘制教学素材，数量与招牌错字用于人工核对练习，不是实际模型测试样本。
- 工作空间图片使用 Unsplash 摄影：<https://images.unsplash.com/photo-1496181133206-80ce9b88a853?auto=format&fit=crop&w=1600&q=85>。实际画面为银色笔记本电脑、黑色屏幕、木桌、金属收纳及绿植；不能描述成屏幕显示山地照片。围绕图片构造的标注任务和框均为本次模拟。
- 预置 ASR 原稿的错误是人为构造；CER 仅演示计算口径，不能成为真实模型成绩。模型评测须区分原始 ASR、独立参考稿和人工修订稿。
- 简历中的历史数量、通过率和提效陈述不作为本演示的实测结果；本次作品不得叙述成过去已上线的生产系统。JSON 通过不能证明转写、语义、审美或合规正确。
